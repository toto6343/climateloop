# 서드파티 폰트 고지 (Third-Party Font Notice)

이 디렉터리에는 PDF 리포트의 한글 출력을 위해 **나눔고딕(NanumGothic)** 폰트가 함께 배포됩니다.

## 번들된 파일

| 파일 | 내용 |
|---|---|
| `NanumGothic.ttf` | 나눔고딕 Regular, Version 3.020 (원본 그대로, 수정하지 않음) |
| `OFL.txt` | SIL Open Font License 1.1 전문 + 나눔 폰트 저작권 고지 |
| `NOTICE.md` | 이 파일 |

## 저작권 및 상표

폰트 파일의 `name` 테이블에 기록된 값을 그대로 옮긴 것입니다.

```
Copyright © 2011 NHN Corporation. All rights reserved.
Font designed by Sandoll Communications Inc.

NanumGothic Regular is a registered trademark of NHN Corporation.

Vendor: NHN Corporation (http://www.nhncorp.com)
Version 3.020
```

`OFL.txt`에 기록된 라이선스 저작권 고지는 다음과 같습니다.

```
Copyright (c) 2010, NHN Corporation (http://www.nhncorp.com),
with Reserved Font Name Nanum, Naver Nanum, NanumGothic, Naver
NanumGothic, NanumMyeongjo, Naver NanumMyeongjo, NanumBrush, Naver
```

## 이 프로젝트의 준수 사항

- 폰트를 **수정하지 않고** 원본 그대로 번들했습니다.
- 저작권 고지와 라이선스 전문(`OFL.txt`)을 폰트와 함께 배포합니다. (OFL 1.1 조건 2)
- **예약 폰트 이름(Reserved Font Name)** 인 `Nanum`, `NanumGothic` 등을 변형본 이름으로 사용하지 않습니다. (조건 3)
- 폰트를 단독으로 판매하지 않습니다. (조건 1)
